# Brako Vault ブラウザー拡張機能 — プライバシーポリシー

施行日: 2026年9月9日

## 適用範囲

本ポリシーは、Chromium 系ブラウザーおよび Firefox 向け Brako Vault
拡張機能と、任意でインストールする Windows ネイティブメッセージング
ホストに適用されます。

## 取り扱うデータ

ローカルの暗号化保管庫にある認証情報を利用するという唯一の目的のため、
拡張機能は次のデータを扱います。

- ユーザー名とパスワードを含む認証情報
- 現在のログインページのオリジンと URL
- 保存または更新候補を作成する際にユーザーが明示的に送信したフォーム
- 設定で入力された保管庫フォルダーと端末名
- ユーザーが選択した保管庫エントリー

拡張機能が読むのはログイン関連のフィールドだけです。タブを横断した閲覧履歴、
Cookie、決済・健康情報、広告識別子、分析、クラッシュレポート、テレメトリーは
収集しません。

## データの利用

データは、ローカル保管庫のロック解除と検索、一致する認証情報の表示、
ユーザーが選んだフィールドへの入力、確認が必要な保存・更新候補の作成にだけ
使用します。Brako Vault がウェブサイトのフォームを自動送信することはありません。

## ローカルのネイティブメッセージング

拡張機能は、ユーザーが別途インストールした Windows プログラム
`com.brakovault.desktop_host` と上記データを交換します。Firefox は Native
Messaging をブラウザー外への送信と分類するため、manifest には認証情報、
閲覧アクティビティ、ウェブサイト上のアクティビティを申告します。

ホストはローカルで動作し、ネットワークへデータを送信しません。Brako Vault、
Google、Mozilla、第三者が保管庫、認証情報、URL、端末名、フォルダーパス、
利用情報を受け取ることはありません。

## 保存と保護

保管庫はユーザーが選んだフォルダーに暗号化ファイル `vault.bvda` として残ります。
ホスト設定は `%LOCALAPPDATA%\Brako Vault\config.json` に保存されます。Windows
Hello のクイック解除を有効にすると、暗号化レコードが
`%LOCALAPPDATA%\Brako Vault\security\quick-unlock.json` に保存されますが、
マスターパスワードやマスターキーの平文は含まれません。

保管庫は AES-256-GCM と Argon2id を使用します。Windows Hello はクイック解除前に
ローカルの Windows ユーザーを確認しますが、保管庫の暗号化を置き換えるものでも、
ハードウェア保護を保証するものでもありません。

## 共有、販売、リモート処理

データを販売、貸与、第三者と共有したり、広告や信用判断に使用したり、
リモートサービスで処理したりしません。ユーザーアカウントやサーバー同期はありません。

## 保持と削除

Brako Vault は遠隔からデータへアクセスしたり削除したりできません。

- Windows Hello を無効にすると `quick-unlock.json` が削除されます。
- ホストのアンインストールでは登録とクイック解除情報を削除しますが、
  `config.json` と保管庫は意図的に保持します。
- ホスト終了後、ユーザーは `config.json` と保管庫を手動で削除できます。
- 拡張機能を削除すると、ブラウザーが管理する拡張機能データも削除されます。

別の暗号化バックアップがなければ、保管庫の削除は元に戻せません。

## 変更と連絡先

重要な変更は、更新日とともに同じ URL で公開します。プライバシーまたは
セキュリティに関する連絡は、
[GitHub の非公開脆弱性報告](https://github.com/waar19/brako-vault-releases/security/advisories/new)
をご利用ください。
